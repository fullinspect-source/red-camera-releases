# RED Camera downloads

RED Camera is a reliable camera for INSPECT on Windows tablets. It replaces the Windows Camera app, which often shows a
black screen after the tablet has been asleep, and saves each photo where INSPECT looks for it.

## Install or update

1. Download **[update_red_camera.bat](https://github.com/fullinspect-source/red-camera-releases/releases/latest/download/update_red_camera.bat)**.
2. Double-click it. If Windows asks whether to run it, choose **Run**.
3. On a first install, answer the two questions. RED Camera then runs in the tray (bottom right).

No administrator rights are needed. Running it again updates RED Camera to the newest release and keeps your settings.

To remove it: Start menu > **Uninstall RED Camera**. Your photos are never deleted.

This repository holds only the downloads; the source code is private.
